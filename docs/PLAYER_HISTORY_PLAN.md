# Просмотр, сезоны и история: первый этап

## Изменения

- Нативный плеер восстанавливает checkpoint конкретной серии до старта.
- Переключение на веб-плеер освобождает нативный контроллер.
- Открытие экрана и ошибка загрузки не считаются подтверждённым просмотром.
- Выбор серий разделён по сезонам; последовательность воспроизведения остаётся хронологической.
- История показывает сезон, серию и сохранённую позицию.
- Существующие ключи и формат локальной библиотеки сохраняются.
- История больше не удаляется при превышении 30/200 записей или окончании Plus.
- Запись и очистка истории выполняются последовательно.

## Ограничения

Сторонний iframe не сообщает надёжные события старта и текущую позицию.
Для него нельзя обещать восстановление секунды или считать загрузку страницы просмотром.
Сохранённый checkpoint той же серии сохраняется при переходе из нативного плеера.
Общие идентификаторы тайтлов между озвучками, фактическая длительность просмотра
и подтверждение завершения серии требуют следующего этапа модели данных.

## Проверки перед слиянием

В текущей сессии выполнено ревью исходников; Flutter tests/analyze и runtime не запускались.

```
flutter test --no-pub
flutter analyze --no-pub
```

На целевой платформе проверить:
1. Открытие неработающей серии не создаёт запись истории.
2. Нативное видео стартует с сохранённой позиции правильной серии.
3. При переходе на веб-плеер нет фонового звука старого контроллера.
4. Быстрое переключение серий не возвращает предыдущий плеер.
5. Две серии с одинаковым номером в разных сезонах различимы.
6. Старые избранное, списки и checkpoints сохраняются после обновления.
7. История свыше 30/200 записей сохраняется после записи и смены подписки.
