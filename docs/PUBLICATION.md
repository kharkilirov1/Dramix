# Публикация исходников

Эта копия подготовлена для GitHub отдельно от рабочего локального проекта.

- API-токены, локальные настройки, cookies, profiles, кэши, сборки, диагностические
  probes и личные screenshots не входят в репозиторий.
- Встроенный production-пул токенов пуст. Приложение сохраняет ввод токена в
  настройках, локальный кэш и получение community-пула во время работы.
- Unit tests используют синтетические значения и mock HTTP, а не действующие
  credentials. Полный тестовый набор не доказывает доступность внешнего API.
- Абсолютный путь к локальной Java убран из Android Gradle config. Выберите
  JDK 17 в своём окружении перед Android-сборкой.
- Токены не должны попадать в commit, сообщения диагностики или GitHub Issues.
- При исходном аудите Web/Windows runtime-проверка после последних изменений
  ещё не была выполнена; прежние screenshots/README-отметки не являются свежим
  подтверждением воспроизведения.

Репозиторий создаётся приватным. Изменение видимости требует отдельного решения
владельца; приватность не заменяет удаление секретов из исходников.
